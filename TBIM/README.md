# TBIM · ข้อมูลสัญลักษณ์งานเขียนแบบ (Drawing annotation)

โฟลเดอร์นี้เก็บทุกอย่างจากงานค้นคว้า "สัญลักษณ์ในงานเขียนแบบ" สำหรับโปรแกรม TBIM เน้นมาตรฐานไทยก่อน แล้วเพิ่มสิงคโปร์ (ตลาดหลักของบริษัท) และมาตรฐานสากลอื่น ๆ
ถ้าเป็นแชทหรือเอเจนต์ที่จะนำข้อมูลไปใช้ต่อ ให้อ่าน [`CONTEXT.md`](CONTEXT.md) ก่อน

## ตัวเลขโดยรวม (แคตาล็อก TBIM-SYM 0.2.0, schema 1.1.0)

- 233 สัญลักษณ์: ไทย 212, สากลที่ไทยไม่มี 14, เฉพาะสิงคโปร์ 7
- 13 สาขา: สถาปัตย์ ทั่วไป โครงสร้าง ไฟฟ้า กระแสอ่อน แจ้งเหตุ ประปา สุขาภิบาล ดับเพลิง ก๊าซ ปรับอากาศ โยธา สำรวจ
- 22 ชุดคำศัพท์ รวม 661 รายการ (รหัสป้าย รหัสท่อ สายไฟ เหล็กเสริม พิกัด/ระดับอ้างอิง ชื่อเลเยอร์ ฯลฯ)
- สถานะ: มาตรฐานที่มีเลขกำกับ 9 · มาตรฐานหน่วยงาน 11 · พบในแบบจริง 58 · ยังไม่ยืนยัน 155
- ทุกสัญลักษณ์มีภาพ SVG ใน `examples/glyphs/` แต่รูปทรงส่วนใหญ่เป็นค่าที่เสนอเอง

## แก้ข้อมูลแล้วทำอะไรต่อ

```bash
python3 TBIM/data/validate.py            # ตรวจ schema, id ซ้ำ, URL ต้องมาจากบันทึก, สร้าง CSV ใหม่
python3 TBIM/examples/build_example.py   # สร้างหน้าตัวอย่างใหม่จาก JSON + glyphs
```
