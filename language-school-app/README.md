# ห้องเรียนอังกฤษ: แอปสำหรับ iPad / iPhone และ Android

แอปจริงที่ติดตั้งลงเครื่องได้ สร้างด้วย [Capacitor](https://capacitorjs.com) โดยใช้โค้ดบทเรียนชุดเดียวกับเวอร์ชันเว็บใน [`../language-school/index.html`](../language-school/index.html) ถ้าแก้บทเรียนที่ไฟล์นั้น ทั้งเว็บและแอปจะได้บทเรียนใหม่เหมือนกัน

## ต่างจากเวอร์ชันเว็บอย่างไร

| | เวอร์ชันเว็บ (ลิงก์ Claude) | แอปนี้ |
|---|---|---|
| ใช้งานออฟไลน์ | ต้องต่อเน็ต | ได้ 100% (ฝังฟอนต์ไว้ในแอป) |
| เสียงอ่าน | เสียงของเบราว์เซอร์ | เสียงของเครื่อง ดังได้แม้เปิดโหมดเงียบ |
| ฝึกออกเสียงผ่านไมค์ | ไม่มี | มี: กดไมค์แล้วพูด แอปบอกว่าคำไหนชัด (เขียว) คำไหนต้องฝึก (แดง) |
| ครู AI | มี | ยังไม่มี (ดูตัวอย่างคำตอบแทน) |
| บันทึกความคืบหน้า | ในบัญชี Claude | ในเครื่องนั้น (ลบแอป = ข้อมูลหาย) |

ปุ่มไมค์อยู่ในบัตรคำศัพท์ บทสนทนา และขั้น "ฝึกพูด" ของทุกบท

## ติดตั้งลง iPad / iPhone (ใช้ Mac)

ทำครั้งแรกประมาณ 20–30 นาที

### 1. เตรียม Mac

1. ติดตั้ง **Xcode** จาก App Store (ไฟล์ใหญ่ ใช้เวลาโหลดนาน)
2. ติดตั้ง **Node.js 22** จาก <https://nodejs.org>
3. เปิดแอป **Terminal** แล้วพิมพ์ทีละบรรทัด:

```bash
git clone https://github.com/snabs1993/kritsada.git
cd kritsada
git checkout claude/keen-volta-6ibcuu
cd language-school-app
npm ci
npm run ios
```

คำสั่ง `npm run ios` จะเตรียมไฟล์แอปแล้วเปิดโปรเจกต์ใน Xcode ให้เอง

### 2. ตั้งค่าใน Xcode (ครั้งแรกครั้งเดียว)

1. แถบซ้ายคลิก **App** (ไอคอนสีฟ้าบนสุด) แล้วเลือกแท็บ **Signing & Capabilities**
2. ช่อง **Team** กด **Add an Account…** ล็อกอินด้วย Apple ID แล้วเลือก *(ชื่อคุณ) (Personal Team)*
3. ถ้าขึ้นข้อความแดงว่าใช้ Bundle Identifier นี้ไม่ได้ ให้แก้ช่อง **Bundle Identifier** เป็นชื่อที่ไม่ซ้ำ เช่น `app.englishclass.kritsada`

### 3. ติดตั้งลง iPad

1. เสียบสาย iPad เข้ากับ Mac แล้วกด **เชื่อถือ (Trust)** บน iPad
2. บน iPad เปิด **ตั้งค่า › ความเป็นส่วนตัวและความปลอดภัย › โหมดนักพัฒนา (Developer Mode)** แล้วรีสตาร์ตตามที่เครื่องบอก
3. ใน Xcode แถบด้านบน เลือกปลายทางเป็น iPad ของคุณ แล้วกดปุ่ม **▶ (Run)**
4. ถ้า iPad บอกว่า "นักพัฒนาไม่น่าเชื่อถือ" ให้ไปที่ **ตั้งค่า › ทั่วไป › การจัดการ VPN และอุปกรณ์** เลือก Apple ID ของคุณ แล้วกด **เชื่อถือ**

ครั้งแรกที่กดไมค์ แอปจะขออนุญาตใช้ไมโครโฟนและการรู้จำเสียงพูด ให้กดอนุญาตทั้งสองอย่าง

### เรื่องที่ควรรู้เกี่ยวกับ Apple ID ฟรี

- แอปจะ **หมดอายุทุก 7 วัน** (เปิดไม่ขึ้น) แก้โดยเสียบสายแล้วกด ▶ Run ใน Xcode อีกครั้ง ความคืบหน้าการเรียนยังอยู่ครบ
- ถ้าสมัคร **Apple Developer Program** (ปีละ 99 USD) แอปจะอยู่ได้ 1 ปี และส่งให้คนในครอบครัวผ่าน TestFlight ได้โดยไม่ต้องเสียบสาย

## ติดตั้งลง Android

### วิธีที่ 1: ดาวน์โหลดไฟล์ APK จาก GitHub (ไม่ต้องติดตั้งโปรแกรมอะไร)

ทุกครั้งที่มีการแก้โค้ด GitHub จะสร้างไฟล์ติดตั้งให้อัตโนมัติ

1. เปิด <https://github.com/snabs1993/kritsada/actions> แล้วเลือก **English class app (Android APK)**
2. กดรายการล่าสุดที่มีเครื่องหมายถูกสีเขียว
3. เลื่อนลงไปที่ **Artifacts** แล้วกด **english-class-apk** เพื่อดาวน์โหลด (ได้ไฟล์ .zip)
4. แตกไฟล์ zip จะได้ `app-debug.apk` แล้วส่งเข้ามือถือ เช่น ผ่าน Google Drive, LINE หรือสาย USB
5. บนมือถือ แตะไฟล์ `app-debug.apk` ถ้าเครื่องถาม ให้อนุญาต **ติดตั้งแอปที่ไม่รู้จัก** สำหรับแอปที่ใช้เปิดไฟล์ แล้วกดติดตั้ง

Google Play Protect อาจเตือนว่าแอปนี้ไม่ได้มาจาก Play Store ให้กด "ติดตั้งต่อไป"

**อัปเดตแอป:** ดาวน์โหลด APK ใหม่แล้วติดตั้งทับได้เลย ความคืบหน้าไม่หาย เพราะทุกไฟล์เซ็นด้วยกุญแจเดียวกัน

### วิธีที่ 2: สร้างเองบน Mac ด้วย Android Studio

ติดตั้ง [Android Studio](https://developer.android.com/studio) แล้วใน Terminal (ในโฟลเดอร์ `language-school-app`) พิมพ์ `npm run android` จากนั้นเสียบมือถือที่เปิด USB debugging แล้วกด ▶ Run

## สำหรับคนแก้โค้ด

| ไฟล์ / โฟลเดอร์ | หน้าที่ |
|---|---|
| `../language-school/index.html` | บทเรียนและหน้าจอทั้งหมด (ใช้ร่วมกับเวอร์ชันเว็บ) |
| `src/native.js` | ตัวเชื่อมกับเครื่อง: เสียงอ่าน, ไมค์, บันทึกข้อมูล, ปุ่มย้อนกลับของ Android |
| `scripts/build-www.mjs` | ประกอบไฟล์แอปลง `www/` (ใส่ส่วนหัว HTML, ฟอนต์ในเครื่อง, `native.js`) |
| `fonts/` | ฟอนต์ Bai Jamjuree, IBM Plex Sans Thai Looped, IBM Plex Mono, Itim (สัญญาอนุญาต SIL OFL 1.1 แนบไว้ในโฟลเดอร์) |
| `assets/` | ภาพต้นฉบับไอคอนและหน้าจอเปิดแอป สร้างขนาดต่างๆ ใหม่ด้วย `npx capacitor-assets generate` |
| `ios/`, `android/` | โปรเจกต์ Xcode และ Android Studio |

หลังแก้ `index.html` ให้รัน `npm run sync` เพื่ออัปเดตทั้งสองแพลตฟอร์ม

**กุญแจเซ็น Android:** `android/app/shared-debug.keystore` เป็นกุญแจสำหรับทดสอบ ถูก commit ไว้โดยตั้งใจ เพื่อให้ APK ทุกไฟล์ติดตั้งทับกันได้ ใช้สำหรับแจกในครอบครัวเท่านั้น ถ้าจะลง Google Play ต้องสร้างกุญแจ release ของตัวเองและเก็บเป็นความลับ
